# TALLOS · Exhibidor 3D

Mockup 3D interactivo del exhibidor TALLOS (Del Bajo). Abre en celular y escritorio.

## Publicar en GitHub Pages
1. Crear un repositorio público en github.com (ej. `tallos-3d`).
2. *Add file → Upload files*: arrastrar **el contenido** de esta carpeta (index.html, three-d-stage.js, tex/, fonts/). index.html tiene que quedar en la raíz.
3. *Settings → Pages → Build and deployment*: Source **Deploy from a branch**, Branch **main**, carpeta **/ (root)** → Save.
4. En 1–2 minutos queda online en `https://<usuario>.github.io/tallos-3d/`.

Para probar en la computadora antes de subir: no abrir index.html con doble clic (el navegador bloquea las texturas). Usar un servidor local, por ejemplo `npx serve` dentro de la carpeta.
